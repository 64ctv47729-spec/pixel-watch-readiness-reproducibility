# Google Pixel Watch 3 Daily Readiness: analysis and reproducibility package

Version 1.0.0 — frozen 28 October 2026

This package supports the analyses reported in *Associations of Google Pixel Watch 3 Daily Readiness With Autonomic Physiology and Self-Reported Wellness: An Exploratory 14-Day Repeated-Measures Study*.

## Contents

- `data/analytic_dataset.csv`: disclosure-reduced analysis data with sequential pseudonymous participant identifiers and synthetic dates.
- `code/`: final association, missingness, prediction, sensitivity, table and figure scripts.
- `output/`: regenerated model summaries, diagnostics, cross-validation assignments, row-level predictions and bootstrap draws.
- `expected_results/`: frozen key results used by automated validation.
- `tables/`: source CSVs for manuscript Tables 1–4 and Supporting Tables S1–S9.
- `figures/`: final manuscript figure previews; publication-resolution versions are regenerated by the workflow.
- `documentation/`: locked analysis decision log, statistical audit and sensitivity-analysis record.
- `environment/`: exact Python requirements and recorded software versions.

Raw questionnaire, onboarding, Kubios and Fitabase exports are not included. Neither are participant-email crosswalks, exact study dates, document QA renders, draft manuscripts or manuscript-editing utilities.

## Reproduce the analyses

Python 3.12 is recommended. Create an isolated environment and install the dependencies:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r environment/requirements.txt
```

Then run:

```bash
./run_analysis.sh
```

The complete run refits the independent Aim 1 and Aim 2 models, executes the participant-cluster bootstraps, reruns the missingness and sensitivity analyses, repeats participant-grouped prediction, regenerates tables and figures, and validates key outputs. It is computationally intensive because it includes multiple 2,000-draw participant-cluster bootstraps.

To validate the included frozen outputs without refitting models:

```bash
./validate_package.sh
```

The original primary Aim 1 and Aim 2 fits used R 4.3.3 with `ordinal` 2023.12-4 and `lme4` 1.1-35.1. The included Python likelihood/REML implementation independently reproduces those estimates and is the portable default workflow. The original R scripts are retained in `code/`.

## Analysis map

- Aim 1: cumulative-logit mixed models of self-reported wellness.
- Aim 2: linear mixed models of independently measured physiology with participant-cluster bootstrap intervals.
- Aim 3: participant-grouped, five-fold cross-validation repeated 20 times, with row-weighted ranked probability score as the primary estimand.
- Sensitivities: participant-level weighting, protocol-restricted samples, duplicate-date exclusion, participant-level centring, inverse-probability weighting, temporal prediction and inclusion of Google Sleep Score.

Differences in ranked probability score are calculated from unrounded estimates; they may not equal subtraction of the displayed rounded component scores.

## Data protection

The dataset is pseudonymized, not guaranteed anonymous. Exact calendar dates, direct identifiers and free text have been removed. Dates are synthetic and preserve only within-participant ordering and episode structure. Consent, ethics, institutional data-governance and disclosure-risk review for this release have been confirmed by the study team. See `PUBLIC_RELEASE_CHECKLIST.md`.

## Interpretation

All analyses are observational and conditional on a manually transcribed Daily Readiness score being available. The package supports reproducibility of the reported associations and predictions; it does not establish causal effects, clinical validity or complete representativeness of all monitored days.
